
# SWYNEX - Exploratory Data Analysis

## Task 2: Exploratory Data Analysis

This project focuses on performing Exploratory Data Analysis (EDA) on a cleaned supermarket sales dataset using Python.

## Objectives
- Analyze the dataset.
- Calculate important statistics.
- Identify trends and patterns.
- Detect anomalies.
- Create meaningful charts and visualizations.
- Generate five useful business insights.

## Tools & Technologies
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Dataset Overview
2. Statistical Analysis
3. Missing Values Analysis
4. Sales Distribution
5. Correlation Heatmap
6. Category-wise Sales Analysis
7. Branch-wise Sales Analysis
8. Payment Method Analysis
9. Five Business Insights
